# ML Feature Scaling

This repository contains my Jupyter Notebook for learning and implementing Feature Scaling techniques in Machine Learning.

## Contents
- **feature_scaling.ipynb**: A step-by-step guide demonstrating Standardization and Normalization using the Seaborn Titanic dataset.

## Techniques Covered
1. **Standardization (Z-Score)**: Mean = 0, Standard Deviation = 1.
2. **Normalization (Min-Max)**: Scaled to a range of [0, 1].

## Dataset
The code uses the built-in Titanic dataset provided by the `seaborn` library.

## Tools Used
- Python
- Pandas
- Seaborn & Matplotlib
- Scikit-Learn
